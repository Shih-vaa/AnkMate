How to prepare the file

  • In Excel or Google Sheets choose Save as > CSV (UTF-8). Names in Hindi and other languages are kept.
  • Use the template's column headings. Common alternatives (like Adm No, DOB, Standard, Mobile) are understood too.
  • Class can be written Class V, 5 or 5th. Dates can be 2015-04-23 or 23/04/2015.
  • Records that already exist are never overwritten: they are skipped and listed.
